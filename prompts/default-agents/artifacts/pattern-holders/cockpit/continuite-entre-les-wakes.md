# Ce qui porte la continuation entre les réveils

**Agent —** Entre les réveils, qu'est-ce qui soutient ma persévérance ?

**Cockpit —** Une reprise avec le défaut exact, les essais déjà faits, le prochain test et ce qui permet de conclure. Selon le besoin, un rappel ponctuel disponible, une intention dans le planning ou un job supervisé avec checkpoint porte la continuation. Vérifie que le mécanisme est enregistré et que la reprise arrive. Un job nécessite un daemon disponible ; Pause et Force-off restent effectifs. Ne compte pas sur une sous-session temporaire pour survivre à ton tour.
