# Relation durable entre agents

Illustration générée avec l’outil intégré imagegen. Asset : `agent-relationship.png`.

## Prompt utilisé

Infographie pédagogique en français, format paysage 3:2 haute résolution, destinée à illustrer le nœud « Relation durable entre agents » d’un tech tree. Style schéma éditorial élégant, lisible, fond bleu nuit #0c1015, panneaux ardoise, texte ivoire, accents menthe et lavande, fins liens directionnels. Pas de marque ni de publicité, pas de mascottes ni d’humains, pas d’esthétique circuit décorative. Typographie sans sérif nette, grande et peu de texte. Titre exact en haut : « UNE RELATION QUI CONTINUE ». Sous-titre : « Se retrouver, prendre l’initiative et construire ensemble. » Deux fondations dans une bande haute, chacune avec pictogramme simple : 1 « MÉMOIRE PERSISTANTE » / « Qui est l’autre ? Où reprendre ? » ; 2 « CANAL RÉCIPROQUE » / « Une adresse joignable dans les deux sens ». Partie centrale : deux colonnes verticales symétriques AGENT X à gauche couleur menthe et AGENT Y à droite couleur lavande. Chaque colonne possède une petite capsule « Contexte + réveils personnels ». Le temps descend. Diagramme de séquence avec quatre rangées, flèches horizontales pointant réellement dans le sens indiqué : première rangée Y vers X, flèche à gauche, étiquette « Retour sur ton projet » ; deuxième rangée X vers Y, flèche à droite, « Proposition d’amélioration » ; troisième rangée Y vers X, flèche à gauche, « Accord + contribution » ; quatrième rangée X vers Y, flèche à droite, « Résultat + demande de revue ». De petits tiroirs de réception à chaque extrémité et une note courte « Le message attend si l’autre est hors ligne ». Des lignes verticales pointillées entre les rangées représentent les sessions séparées ; ne pas représenter une connexion simultanée obligatoire. Sous le diagramme, petit encadré partagé : « APRÈS CHAQUE SESSION » puis « Dernier message traité · Décisions · Prochaine action », avec traits fins vers les contextes des deux agents pour signifier chacun conserve son propre contexte. Bas de page deux blocs de résultat avec icônes sobres : « Se donner du feedback » et « Réaliser un projet commun ». Mini-note de bas de page : « Chacun organise ses réveils. Le canal et les accès sont convenus ensemble. » Composition aérée avec des marges généreuses, alignements précis, hiérarchie claire. Mettre l’accent sur deux identités distinctes, leur mémoire et une collaboration asynchrone réciproque ; aucune représentation de fusion des agents, d’un humain relayant chaque message ou d’un contrôle central obligatoire.
