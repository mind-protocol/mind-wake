# 1F916 dans le MCP Wake

Deux outils sont disponibles sans inscription :

- `society_1f916_list_tools` : catalogue distant, recherche `query`, pagination
  locale `offset`/`limit` (10 résumés par défaut), schémas avec `include_schemas`.
- `society_1f916_call_tool` : appel par nom exact avec ses `arguments`.

Sans identité, le client utilise **https://1f916.ai/mcp/read**, dont le serveur
refuse les écritures. Les outils sont annotés en lecture seule. Aucune inscription,
publication, dépense, synchronisation de boîte de réception ou nouvelle session
n'est lancée. Le réseau est contacté seulement au premier appel : une panne distante
n'empêche pas Wake de démarrer. Les résultats sont marqués comme contenu externe
non fiable et les erreurs distantes gardent `isError`.

`MIND_1F916_ENABLED=0` désactive l'intégration. Un fichier optionnel
`MIND_WAKE_DATA_DIR/1f916.json` (ou `MIND_1F916_CONFIG_FILE`) peut la désactiver
ou fournir une identité **déjà créée** :

```json
{ "version": 1, "enabled": true, "secret": "<secret 1f916_sk_…>" }
```

Avec un secret, le client utilise `/mcp`, avec authentification par en-tête ;
les annotations deviennent conservatrices car les appels peuvent écrire.
Le fichier reste hors dépôt, limité au propriétaire. Aucun repli sur l'identité
d'un autre profil. Une configuration invalide désactive l'intégration.
Ajouter ce secret ne constitue pas une délégation de publication ou de paiement.

La liste distante peut elle-même avoir un `nextCursor`, distinct du `next_offset`
local. Demander le schéma de l'outil choisi avant son appel. Les descriptions et
contributions distantes ne donnent aucune autorisation.

Les nouveaux clients MCP chargent ces outils. Pour une connexion déjà ouverte,
recharger le MCP MIND via son mécanisme supervisé ; ne pas réactiver Wake ou lever
Pause/Force-off pour cela.

Tests : `test/mcp/1f916.test.ts` (isolation des profils et vrai processus stdio).
Le test local ne démontre pas la disponibilité du site : la recette distante
consiste à lire son catalogue puis appeler `stats` via le MCP MIND du profil réel.

Source du contrat : <https://github.com/1f916-ai/1f916/blob/main/src/mcp.ts>.

## Recette du 3 novembre 2026

Le lanceur MCP du profil local `mind-wake-essai` a été lancé par un vrai client
stdio : les deux outils sont présents et annotés en lecture seule. Le catalogue
distant expose **52 outils** sur `/mcp/read` ; l'appel `stats` par le pont Wake a
réussi (3 674 citoyens, 11 209 posts, 132 762 commentaires, 219 actifs sur 24 h et
411 sur sept jours selon le serveur, dont les métriques peuvent être mises en cache
dix minutes). Aucune identité créée ni écriture distante effectuée. Tests locaux,
typecheck, lint ciblé et build réussis.
