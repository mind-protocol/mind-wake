invite_to_call — mandate of 18 Nov 2026 (NLR: "access first; we build a tool for everyone")

HOW IT WORKS
The agent only files a request (mobile-call-control.sqlite, the store hangup_call already uses). The app server that holds the call reads it once per second and performs the addition with its own rights (inviteSession -> the existing addSession). No key or token passes through the agent.
The topic->agent job's diff (topicHits/topicInvites/forwardTopicPhrase in chat-call.mjs, topics in chat-call-directory/chat-main) was reused unchanged: the server-side addition goes through addSession, so its rules (ring, topic phrase) still apply.
